# Midnight Broomstick Ride

Darsh and Ryan's Haunted Harvest project using Option 5 from the assignment.

## Scene Plan

1. Departure at Dusk
2. Across the Midnight Sky
3. Haunted Arrival

## Project Files

- `index.html` contains the page structure and three scenes.
- `haunted-harvest.css` contains all custom styles.
- `submission_Template_halloween.html` contains the team and submission details.
- `assets/images/` is for image and SVG files.
- `assets/fonts/` is for local font files if needed.

The project uses only HTML and CSS. Do not add JavaScript.
